# 🛍️ Анализ ассортимента интернет-магазина (ABC/XYZ-анализ)

## 📌 Описание проекта

Провести комплексный анализ ассортимента британского интернет-магазина подарков и товаров для дома на основе транзакционных данных за 14 месяцев. Цель: оценить структуру ассортимента, выделить группы SKU по экономической значимости (ABC) и вариативности спроса (XYZ), а также сформировать обоснованный список кандидатов на сокращение с оценкой потенциального эффекта.

**Ключевые элементы:**
- **Очистка и предобработка данных:** удаление дубликатов, отмен, служебных операций и аномальных значений.
- **ABC-анализ:** классификация товаров по их вкладу в выручку (A - 80%, B - 15%, C - 5%).
- **Динамический ABC-анализ:** отслеживание миграции SKU между категориями по кварталам для выявления «восходящих» и «падающих» звёзд.
- **XYZ-анализ:** классификация товаров по коэффициенту вариации спроса (X - стабильный, Y - умеренный, Z - нестабильный).
- **Объединённая матрица ABC/XYZ:** сегментация ассортимента на 9 групп для разработки стратегий управления.
- **Формирование списка кандидатов на сокращение:** отбор SKU по ряду фильтров (низкая выручка, нестабильный спрос, узкая клиентская база и т.д.).
- **Оценка потенциального эффекта:** расчёт доли выручки, которую формируют кандидаты на вывод.

---

## 🔧 Основные этапы работы

1.  **Загрузка и первичный анализ данных:**
    *   Загрузка датасета `online_retail.csv` (более 1 млн строк).
    *   Анализ пропусков, типов данных, дубликатов и временного диапазона.
    *   Выявление и исследование аномалий: отмены, отрицательные количества, нулевые цены, служебные коды.

2.  **Очистка данных:**
    *   Удаление отменённых заказов (Invoice, начинающиеся с 'C').
    *   Исключение строк с `Quantity <= 0` и `Price <= 0`.
    *   Удаление служебных `StockCode` (POST, DOT, M, BANK CHARGES и т.д.).
    *   Удаление полных дубликатов.
    *   Фиксация периода анализа (14 полных месяцев: 2010-10-01 — 2011-11-30).

3.  **ABC-анализ:**
    *   Расчёт выручки по каждому SKU.
    *   Присвоение категорий A, B, C на основе накопленной доли выручки (80/95%).
    *   Визуализация кривой Парето.

4.  **Динамический ABC-анализ:**
    *   Проведение ABC-анализа для каждого полного квартала.
    *   Построение матрицы переходов для отслеживания миграции SKU между категориями.
    *   Выявление «восходящих звёзд» (C → A/B) и «падающих звёзд» (A/B → C).

5.  **XYZ-анализ:**
    *   Построение помесячной динамики продаж для каждого SKU с учётом нулевых месяцев.
    *   Расчёт коэффициента вариации (CV).
    *   Присвоение категорий X, Y, Z на основе пороговых значений CV (0.5 и 1.0).

6.  **Объединённый ABC/XYZ-анализ:**
    *   Создание сводной матрицы, объединяющей ABC и XYZ категории.
    *   Анализ девяти групп (AX, AY, AZ, BX, BY, BZ, CX, CY, CZ) по количеству SKU и доле в выручке.

7.  **Отбор кандидатов на сокращение:**
    *   Применение комплекса фильтров к группам CZ и BZ: узкая клиентская база (<20 покупателей), низкая активность (<10 месяцев), невысокая цена (≤£10), исключение новинок.
    *   Сравнение базового и альтернативного (с фильтром `StableC`) вариантов отбора.
    *   Формирование итогового списка и сохранение его в `candidates_for_removal.csv`.

8.  **Оценка эффекта:**
    *   Расчёт доли SKU-кандидатов в общем ассортименте и их доли в общей выручке.
    *   Сравнение средней выручки кандидатов и остальных товаров.
